# Acceptance Criteria

## A. Architecture

- [ ] Required skill directories exist.
- [ ] Each skill has a complete `SKILL.md`.
- [ ] Progressive disclosure is followed.
- [ ] Resource directories are supported where needed.

## B. Technology

- [ ] Next.js 15 / App Router
- [ ] Shadcn/ui
- [ ] Tailwind CSS
- [ ] Recharts
- [ ] D3 on demand
- [ ] Zustand
- [ ] React Query
- [ ] Firebase Firestore/Auth
- [ ] React Hook Form
- [ ] Zod
- [ ] Framer Motion
- [ ] next-intl

## C. Dashboard

- [ ] Dashboard first screen exists.
- [ ] Three real-time chart types exist.
- [ ] Charts occupy 60%+ of first-screen area.
- [ ] Data is visual-first.
- [ ] List items contain visual status indicators.
- [ ] Responsive chart behavior is verified.

## D. Empty / Loading / Feedback

- [ ] Empty state uses illustration + guiding action.
- [ ] Loading state uses skeletons.
- [ ] Success/failure uses toast with icon + semantic color.
- [ ] Toast message length is <= 8 words.

## E. Bilingual

- [ ] EN route works.
- [ ] FA route works.
- [ ] Language switching works.
- [ ] All visible labels are translated.
- [ ] FA switches to RTL.
- [ ] Numbers and dates follow locale.
- [ ] Chart labels are translated.

## F. QC

- [ ] QC-1 passed.
- [ ] QC-2 passed.
- [ ] QC-3 passed.
- [ ] QC-4 passed.
- [ ] `npm run qc` passed.

## G. Traceability

- [ ] Every requirement is mapped.
- [ ] Every `✅` has evidence.
- [ ] No `✅` exists without evidence.
- [ ] Known limitations are documented as `⚠️`.
- [ ] Missing implementation is `❌`.
- [ ] In-progress work is `🔄`.

## H. Final

- [ ] Full QC passed.
- [ ] Bilingual smoke tests passed.
- [ ] RTL screenshot comparison passed.
- [ ] Evidence folder is complete.
- [ ] Comparison Map is final.
